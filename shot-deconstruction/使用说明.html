WORKFLOW

Skill 内部会经历什么

观察、镜头判断和提示词重构彼此分离，避免把猜测直接写成生成指令。

接收与预检确认视频可读取，记录文件名、哈希、时长、分辨率和帧率。
视频观察浏览全片，按动态复杂度抽取关键帧和必要的连续帧。
镜头拆分根据硬切、转场和画面结构变化判断最终镜头边界。
提示词重构按固定信息逻辑组织内容，再根据镜头动态复杂度压缩为自然语言导演指令。
报告交付生成 HTML、Markdown、JSON 和复用索引，供人和 Agent 使用。
关于高清素材：视频超过 1080p 或最长边超过 1920 像素时，Skill 会创建较小的分析代理来减少处理成本；原视频不会被修改。
TEXT PROMPT

纯文字提示词包含什么

每个镜头只输出一种可独立使用的纯文字提示词。信息逻辑保持稳定，篇幅和时间表达随镜头复杂度变化。

纯文字复刻 · Text-to-Video

固定逻辑，动态篇幅

按“主体与核心动作、场景空间、动作时序、摄影机、光影风格、可选声音、稳定约束”组织，再压缩成自然语言，不机械显示标题。

  • 静态或微动作镜头简写为两至三句
  • 标准动作使用“开始时、随后、最后”
  • 复杂连续动作使用“触发、展开、完成”
  • 稳定要求优先采用少量正向约束
夜晚便利店门口，一名穿米白色风衣的短发女性侧身站在玻璃门前。开始时，她的视线停留在画面外；随后先移动目光，再缓慢转头看向摄影机；最后正面注视镜头，动作自然减速并稳定停留。摄影机以平视中景缓慢推进，随着人物转头逐渐过渡到中近景，将注意力集中到她的表情。便利店内部的蓝绿色冷光穿过玻璃，背景形成柔和散景，浅景深、低饱和冷色调、真实商业摄影质感。保持人物面部、手部、发型、服装和便利店空间结构稳定。
使用目标处理方式
只能输入文字使用纯文字复刻提示词
只想借鉴导演语言，不复刻人物编辑提示词中的主体和场景描述，保留动作、构图与运镜

OUTPUT

会输出哪些文件

四个文件位于同一个哈希资产目录中。HTML 是主要用户界面，其他文件分别服务于复制、自动化和复用。

analysis.html

最重要的用户交付。离线图文报告，逐镜头显示截图、观察摘要、纯文字提示词、连续性和不确定项。

analysis.md

纯文本审阅版，适合全文搜索、快速复制提示词，或放入知识库。

analysis.json

机器读取入口，保存精确时间、观察字段和纯文字提示词，供其他 Agent 或自动化流程使用。

manifest.json

复用索引，记录版本、创建时间、输入视频哈希和三个分析文件的路径。

FAQ

常见问题

“反推提示词”能还原原作者的原始 Prompt 吗？

不能保证。不同提示词和参考素材可能生成相似结果。Skill 的目标是反推出更可能复现该镜头的生成条件，而不是声称找回唯一的原始 Prompt。

提示词需要配合源视频使用吗？

不需要。每条提示词必须自包含地描述画面内容和镜头内变化，可直接用于文字生成入口。

长镜头会因为动作很多而被拆碎吗？

通常不会。人物移动、摄影机运动、景别或对焦变化发生在连续拍摄内时，仍作为同一镜头，用开始状态、动作链、结束状态和镜头运动描述内部变化。

再次分析同一个视频会重复工作吗？

Skill 使用完整视频 SHA-256 查找已有资产。发现可用的同哈希结果时会先报告并优先复用，除非你明确要求重新分析。

临时关键帧和代理视频会被自动删除吗？

不会未经确认自动删除。交付后若存在临时文件，Skill 会告知目录并询问是否清理；正式的四个交付文件始终保留。

RIGHTS & PRIVACY

权利与隐私提醒

镜头复现不仅是技术问题，也涉及输入素材的授权范围。

内容权利

可识别真人、品牌和受保护角色会优先转写为中性特征；平台水印、账号标识和非场景字幕不会作为应复刻内容进入提示词。

敏感素材

视频理解通常需要视觉模型读取抽取帧。处理私密、商业机密或其他敏感视频前，请确认当前运行环境和视觉服务的数据处理方式。
