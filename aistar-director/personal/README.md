# Personal Layer

本目录只保存当前使用者的个人偏好、规则、案例与进化记录，不随公共 Base Skill 分发。

首次使用个人层时，从 `../templates/personal/` 复制所需模板，并移除文件名末尾的 `-template`：

```text
personal-profile-template.md     → personal-profile.md
personal-rules-template.md       → personal-rules.md
personal-preferences-template.md → personal-preferences.md
```

个人案例放入 `personal-cases/`，进化日志放入 `evolution-log/`。除本说明和 `.gitignore` 外，本目录内容默认不会被 Git 跟踪。
