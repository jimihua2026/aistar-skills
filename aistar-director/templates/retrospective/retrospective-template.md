# Retrospective Template

> 本模板只定义项目复盘的输出结构，复盘机制与建议规则见 `references/evolution.md`。
> 触发时机：项目进入 `COMPLETED` 之后，不打断进行中的创作。

---

### 3. 复盘四问

```text
① 用户反复改了什么？
② 哪里生成失败或返工？（定位问题层：Prompt / Storyboard / Script / Brief）
③ 哪条规则帮了忙或添了乱？
④ 有没有值得沉淀的新经验？
```

## 7. 改进建议（最多 5 条，按价值排序）

type: rule | template | case

  本项目及历史项目中的证据（含置信度：低 / 中 / 高）。

  适用范围与不适用边界。

## 8. 用户决定

```text
每条建议：【采纳】【暂不采纳】【忽略】

采纳后直接生效（ACTIVE），不再设试行期；
后续失效时可删除或降级（DEPRECATED）。
```

## 9. 安全自查

```text
□ 每条建议是否都有证据
□ 是否有仅凭单次反馈就建议建立正式规则的项（禁止）
□ 是否有建议与 Fact Lock / 客户明确要求冲突（禁止）
□ 是否全部建议都已声明适用边界
```
