# Prompt Template · MULTI_SHOT（多镜头连续生成）

> 适用：多个叙事连续的简单镜头，优先在一次生成中完成。
> 时长原则：在风险可控时尽量使用平台当前支持的较完整时长；若连续性或一致性风险升高，可适当缩短，但不应无理由生成零散短片段。
> 硬规则：连续画面优先在同一个 Prompt 内完成，减少独立片段硬拼；不为凑满平台时长塞入复杂镜头。
> 每个时间分段仍遵守"一镜一核心 Beat"，并明确前一段如何进入后一段。

## 交付结构

### ① 可直接复制的 Prompt

```text
【总体风格】
{全片统一的视觉语言：质感/光线/色彩，继承视觉锚点}

【时间轴】
0-4s：{场景与起始状态}，{主体完成第一个核心动作}，{运镜}；结尾保留{可被下一段接续的动作/视线/运动方向}。
4-8s：承接上一段的{动作/视线/运动方向}自然进入{下一场景或下一构图}，{主体完成第二个核心动作}，{运镜}；避免突兀跳切。
8-12s：继续保持{人物/产品/场景/光线/运动方向}一致，{主体完成结果动作}，{运镜}，最终停在{稳定落版画面}并保持约 0.5～1 秒。
12-15s（需要时）：在前一段结果状态上继续推进{收束动作或视觉重点}，以{下一镜可接的稳定状态}结束。

【声音】
BGM：{情绪与节奏方向}
环境音：
音效：
对白/人声：

【参考素材】
@IMG-01：{唯一职责，如人物外观}
@IMG-02：{场景构图}

【一致性要求】
保持{人物/产品/场景/光线}在所有时间段一致。

【约束】
{少量必要约束，正向描述优先}
```

### ② 使用方式

```text
模式：多镜头连续生成
参考素材：@IMG-01、@IMG-02
建议时长：优先使用平台当前支持的较完整时长；风险升高时适当缩短
生成后：{后期事项}
```

### ③ 风险提示

```text
{跨分段一致性风险；复杂分段建议拆为独立生成}
```

## 拆分红线

出现以下任一情况，放弃 MULTI_SHOT，拆为独立 SINGLE_SHOT：

```text
某分段包含多人物互动
某分段需要精确口型/对话
分段之间主体或场景发生切换且需要强一致性
总复杂度达到 L4
```
