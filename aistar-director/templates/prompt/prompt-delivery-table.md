## 使用规则

- Prompt 正文单独提供，便于直接复制到即梦。
- 表格只承载执行信息，不替代 Prompt 正文。
- 参考素材必须注明各自主职责，避免同一属性出现冲突来源。
- 起始状态应承接上一镜结束状态；若无法承接，明确采用硬切或其他转场理由。
- 主要制作路径用于说明 AI、参考素材和后期的组合方式，不作为工作模式编号。
